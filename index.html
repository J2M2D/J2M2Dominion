Standings Tiebreakers:
League Points → Total Victory Points (VP) → Total Wins

Game Scoring:
First place in each game earns 3 points, second place earns 2 points, third place earns 1 point, and fourth place earns no points.

Game Ties:
When players tie in a game, they share the total points for the positions they occupy.
Example: A tie for 2nd place shares the points for 2nd and 3rd (2 + 1 = 3), so each player receives 1.5 points.
